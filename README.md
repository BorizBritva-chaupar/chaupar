# Чаупар — онлайн

Старинная индийская игра на вышитом поле. Играйте с ботами на одном устройстве или с друзьями онлайн: на телефоне и на компьютере. Игру можно установить как приложение.

## Что внутри

| Файл | Зачем |
|---|---|
| `server.js` | Сервер: раздаёт игру и держит онлайн-комнаты. Без сторонних библиотек, нужен только Node.js 18+. |
| `public/index.html` | Сама игра. |
| `public/manifest.webmanifest`, `public/sw.js`, `public/icons/` | Установка как приложение и работа без интернета (игра с ботами). |
| `render.yaml` | Настройка для бесплатного хостинга Render. |
| `tools/` | Исходник игры одним файлом и скрипты сборки — для правок. |

## Как выложить в интернет (бесплатно, через Render)

1. Зарегистрируйтесь на **github.com**.
2. Нажмите **New repository**, назовите, например, `chaupar`, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите туда **все файлы и папки** из этого архива (не саму папку, а её содержимое). Нажмите **Commit changes**.
4. Зарегистрируйтесь на **render.com** (можно войти через GitHub).
5. Нажмите **New → Web Service**, выберите репозиторий `chaupar`.
6. Заполните:
   - Runtime: **Node**
   - Build Command: `echo ok`
   - Start Command: `node server.js`
   - Instance Type: **Free**
7. Нажмите **Create Web Service**. Через пару минут появится адрес вида `https://chaupar.onrender.com` — это ваша игра.

> На бесплатном тарифе Render «засыпает», если игрой никто не пользуется 15 минут. Первое открытие после этого занимает около минуты. Пока сервер спит или перезапускается, открытые комнаты пропадают — нужно создать новую.

## Как играть онлайн

1. Откройте игру, во вкладке **Онлайн** напишите своё имя и нажмите **Создать комнату**.
2. Нажмите **Пригласить** — отправьте ссылку друзьям (или продиктуйте код из 4 букв).
3. Друзья открывают ссылку и нажимают **Сесть сюда** у свободного цвета.
4. Пустые места можно отдать ботам. Нажмите **Начать игру**.

Кто создал комнату — ведущий: на его устройстве бросаются кубики и ходят боты. Если ведущий выйдет, ведущим станет следующий игрок, а его место займёт бот. Если игрок закрыл страницу, за него ходит бот; когда он вернётся по той же ссылке с того же устройства, место вернётся к нему.

## Как установить как приложение

- **Компьютер (Chrome, Edge):** в адресной строке значок «Установить» (монитор со стрелкой) → **Установить**.
- **Android (Chrome):** меню ⋮ → **Добавить на главный экран** / **Установить приложение**.
- **iPhone (Safari):** кнопка **Поделиться** → **На экран «Домой»**.

## Запуск у себя на компьютере (для проверки)

1. Установите Node.js с **nodejs.org** (версия LTS).
2. Откройте папку игры в терминале и выполните: `node server.js`
3. Откройте в браузере `http://localhost:3000`.
4. Телефон в той же Wi‑Fi сети может зайти по адресу компьютера, например `http://192.168.1.5:3000` (адрес покажет команда `ipconfig` на Windows). Установка как приложение по такому адресу не работает — для неё нужен `https`, то есть хостинг.

## Правки

Игра собрана из одного файла `tools/chaupar.html`. Если поменяли его, пересоберите страницу:

```
python3 tools/build.py tools/chaupar.html public/index.html
```
